# orch Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A local daemon + CLI + MCP server that routes coding tasks to Claude Code or Codex and fails over to the other agent on rate limit or failure.

**Architecture:** A pure `core` library (router, runner, rate-limit detector, handoff, state, orchestrator) with no knowledge of transport. A daemon wraps `core` behind a newline-delimited JSON protocol on a unix socket. The `orch` CLI and the MCP server are thin clients of that socket.

**Tech Stack:** TypeScript (ESM, NodeNext), Node >= 20, `yaml`, `@modelcontextprotocol/sdk`, `zod`, `vitest`, `tsx`.

**Spec:** `docs/superpowers/specs/2026-10-15-orch-design.md`

## Global Constraints

- Language/runtime: TypeScript on Node >= 20, ESM.
- Daemon socket: `~/.orch/sock`; state file: `~/.orch/state.json` (`ORCH_HOME` env overrides `~/.orch`, used by tests).
- At most one failover per task.
- Recursion guard: env `ORCH_DEPTH`; a request with depth >= 1 is rejected.
- Rate-limit patterns live in config, not code.
- Handoff v1 = original prompt + `git status`/`git diff`; v2 adds a summary from the first agent when it can still respond.
- Automated tests never call the real `claude` or `codex` binaries.
- Agents are spawned without a shell; the prompt is always exactly one argv element.
- Non-limit failures (non-zero exit, spawn error) also trigger the single failover but set no cooldown. Only a rate-limit match sets a cooldown.

## Review Focus

Input classes the spec implies but does not spell out; each has a pinning test in the task named.

1. State file missing, empty, or corrupt JSON must behave as "no cooldowns", never crash (Task 2).
2. Agent binary not installed (spawn ENOENT) must fail over, not crash; prompt beginning with `-` or containing quotes/newlines must reach the agent verbatim (Task 4, Task 6).
3. Working directory that is not a git repo must still produce a handoff (Task 5).
4. Huge `git diff` must be truncated, not blow up the prompt (Task 5).
5. Stale socket file left by a crashed daemon must not block start; a live daemon must not be clobbered (Task 8).

```ts
export type AgentName = "claude" | "codex";
export type Outcome = "ok" | "limited" | "failed";

export interface AgentConfig {
  command: string;
  /** argv template; every "{prompt}" substring is replaced by the prompt */
  args: string[];
  /** argv template used to ask the agent for a summary (handoff v2); omit to disable */
  summaryArgs?: string[];
  /** case-insensitive regexes matched against stderr+stdout of a non-zero exit */
  limitPatterns: string[];
  defaultCooldownSec: number;
}

export interface RouteRule {
  /** case-insensitive regex tested against the prompt */
  match: string;
  agent: AgentName;
}

export interface Config {
  defaultAgent: AgentName;
  agents: Record<AgentName, AgentConfig>;
  rules: RouteRule[];
}

export interface RunResult {
  exitCode: number | null;
  stdout: string;
  stderr: string;
}

export interface RunOptions {
  cwd: string;
  depth: number;
  onChunk?: (text: string) => void;
  timeoutMs?: number;
}

export type RunFn = (
  command: string,
  args: string[],
  prompt: string,
  opts: RunOptions,
) => Promise<RunResult>;

export interface Attempt {
  agent: AgentName;
  outcome: Outcome;
  exitCode: number | null;
  stderr: string;
}

export interface TaskResult {
  status: "ok" | "failed" | "rejected" | "unavailable";
  agent: AgentName | null;
  output: string;
  failedOver: boolean;
  attempts: Attempt[];
  message?: string;
}

export interface JobEntry {
  at: number;
  agent: AgentName | null;
  status: TaskResult["status"];
  failedOver: boolean;
  promptPreview: string;
}
```

```ts
import { existsSync, readFileSync } from "node:fs";
import { homedir } from "node:os";
import { join } from "node:path";
import { parse } from "yaml";
import type { AgentName, Config } from "./types.js";

export const AGENT_NAMES: AgentName[] = ["claude", "codex"];

const LIMIT_PATTERNS = [
  "rate.?limit",
  "usage limit",
  "quota",
  "too many requests",
  "limit reached",
  "overloaded",
];

export const DEFAULT_CONFIG: Config = {
  defaultAgent: "claude",
  agents: {
    claude: {
      command: "claude",
      args: ["-p", "{prompt}"],
      summaryArgs: ["-c", "-p", "{prompt}"],
      limitPatterns: LIMIT_PATTERNS,
      defaultCooldownSec: 3600,
    },
    codex: {
      command: "codex",
      args: ["exec", "{prompt}"],
      summaryArgs: ["exec", "resume", "--last", "{prompt}"],
      limitPatterns: LIMIT_PATTERNS,
      defaultCooldownSec: 3600,
    },
  },
  rules: [
    { match: "refactor|architecture|migrate|redesign", agent: "claude" },
    { match: "typo|rename|quick|small fix|one-liner", agent: "codex" },
  ],
};

export function orchHome(): string {
  return process.env.ORCH_HOME ?? join(homedir(), ".orch");
}

export function loadConfig(path?: string): Config {
  const file = path ?? process.env.ORCH_CONFIG ?? join(orchHome(), "config.yaml");
  if (!existsSync(file)) return structuredClone(DEFAULT_CONFIG);
  const raw = parse(readFileSync(file, "utf8")) ?? {};
  const cfg: Config = {
    defaultAgent: raw.defaultAgent ?? DEFAULT_CONFIG.defaultAgent,
    agents: {
      claude: { ...DEFAULT_CONFIG.agents.claude, ...(raw.agents?.claude ?? {}) },
      codex: { ...DEFAULT_CONFIG.agents.codex, ...(raw.agents?.codex ?? {}) },
    },
    rules: raw.rules ?? structuredClone(DEFAULT_CONFIG.rules),
  };
  validate(cfg);
  return cfg;
}

function assertRegex(source: string): void {
  try {
    new RegExp(source, "i");
  } catch {
    throw new Error(`"${source}" is not a valid regex`);
  }
}

function validate(cfg: Config): void {
  if (!AGENT_NAMES.includes(cfg.defaultAgent)) {
    throw new Error(`defaultAgent must be one of ${AGENT_NAMES.join(", ")}`);
  }
  for (const rule of cfg.rules) {
    if (!AGENT_NAMES.includes(rule.agent)) {
      throw new Error(`rule agent "${rule.agent}" must be one of ${AGENT_NAMES.join(", ")}`);
    }
    assertRegex(rule.match);
  }
  for (const name of AGENT_NAMES) {
    cfg.agents[name].limitPatterns.forEach(assertRegex);
  }
}
```

```ts
import { mkdirSync, readFileSync, renameSync, writeFileSync } from "node:fs";
import { dirname } from "node:path";
import type { AgentName, JobEntry } from "./types.js";

interface StateFile {
  cooldowns: Partial<Record<AgentName, number>>;
  jobs: JobEntry[];
}

const MAX_JOBS = 50;

export class StateStore {
  constructor(private readonly path: string) {}

  private read(): StateFile {
    try {
      const data = JSON.parse(readFileSync(this.path, "utf8"));
      return {
        cooldowns: data.cooldowns ?? {},
        jobs: Array.isArray(data.jobs) ? data.jobs : [],
      };
    } catch {
      return { cooldowns: {}, jobs: [] };
    }
  }

  private write(state: StateFile): void {
    mkdirSync(dirname(this.path), { recursive: true, mode: 0o700 });
    const tmp = `${this.path}.${process.pid}.tmp`;
    writeFileSync(tmp, JSON.stringify(state, null, 2));
    renameSync(tmp, this.path);
  }

  cooldownUntil(agent: AgentName): number {
    return this.read().cooldowns[agent] ?? 0;
  }

  isCooling(agent: AgentName, now: number = Date.now()): boolean {
    return this.cooldownUntil(agent) > now;
  }

  setCooldown(agent: AgentName, untilMs: number): void {
    const s = this.read();
    s.cooldowns[agent] = untilMs;
    this.write(s);
  }

  appendJob(entry: JobEntry): void {
    const s = this.read();
    s.jobs.push(entry);
    s.jobs = s.jobs.slice(-MAX_JOBS);
    this.write(s);
  }

  snapshot(): StateFile {
    return this.read();
  }
}
```

```ts
import type { Outcome, RunResult } from "./types.js";

export function classify(result: RunResult, patterns: string[]): Outcome {
  if (result.exitCode === 0) return "ok";
  const text = `${result.stderr}\n${result.stdout}`;
  for (const p of patterns) {
    if (new RegExp(p, "i").test(text)) return "limited";
  }
  return "failed";
}
```

```ts
import type { AgentName, Config } from "./types.js";

export function otherAgent(a: AgentName): AgentName {
  return a === "claude" ? "codex" : "claude";
}

function preferredAgent(config: Config, prompt: string): AgentName {
  for (const rule of config.rules) {
    if (new RegExp(rule.match, "i").test(prompt)) return rule.agent;
  }
  return config.defaultAgent;
}

export function pickAgent(
  config: Config,
  prompt: string,
  isCooling: (a: AgentName) => boolean,
): AgentName | null {
  const preferred = preferredAgent(config, prompt);
  if (!isCooling(preferred)) return preferred;
  const alt = otherAgent(preferred);
  return isCooling(alt) ? null : alt;
}
```

```ts
import { spawn } from "node:child_process";
import type { RunFn, RunResult } from "./types.js";

export function renderArgs(args: string[], prompt: string): string[] {
  return args.map((a) => a.split("{prompt}").join(prompt));
}

export const runCommand: RunFn = (command, args, prompt, opts) =>
  new Promise<RunResult>((resolve) => {
    let stdout = "";
    let stderr = "";
    let settled = false;
    let timer: NodeJS.Timeout | undefined;

    const finish = (r: RunResult) => {
      if (settled) return;
      settled = true;
      if (timer) clearTimeout(timer);
      resolve(r);
    };

    const child = spawn(command, renderArgs(args, prompt), {
      cwd: opts.cwd,
      env: { ...process.env, ORCH_DEPTH: String(opts.depth + 1) },
      stdio: ["ignore", "pipe", "pipe"],
    });

    if (opts.timeoutMs) {
      timer = setTimeout(() => {
        child.kill("SIGKILL");
        finish({ exitCode: null, stdout, stderr: `${stderr}\norch: timed out` });
      }, opts.timeoutMs);
    }

    child.stdout.on("data", (b: Buffer) => {
      const text = b.toString();
      stdout += text;
      opts.onChunk?.(text);
    });
    child.stderr.on("data", (b: Buffer) => {
      stderr += b.toString();
    });
    child.on("error", (err) =>
      finish({ exitCode: null, stdout, stderr: `orch: failed to start ${command}: ${err.message}` }),
    );
    child.on("close", (code) => finish({ exitCode: code, stdout, stderr }));
  });
```

```ts
import { execFile } from "node:child_process";
import { promisify } from "node:util";
import type { AgentName } from "./types.js";

const exec = promisify(execFile);

export const MAX_DIFF_CHARS = 20_000;

export interface HandoffInput {
  prompt: string;
  cwd: string;
  previousAgent: AgentName;
  reason: "limited" | "failed";
  summary?: string;
}

async function git(cwd: string, args: string[]): Promise<string | null> {
  try {
    const { stdout } = await exec("git", args, { cwd, maxBuffer: 50 * 1024 * 1024 });
    return stdout;
  } catch {
    return null;
  }
}

function truncate(text: string): string {
  if (text.length <= MAX_DIFF_CHARS) return text;
  const dropped = text.length - MAX_DIFF_CHARS;
  return `${text.slice(0, MAX_DIFF_CHARS)}\n... [diff truncated, ${dropped} more chars]`;
}

export async function buildHandoff(input: HandoffInput): Promise<string> {
  const { prompt, cwd, previousAgent, reason, summary } = input;
  const status = await git(cwd, ["status", "--short"]);
  const diff = (await git(cwd, ["diff", "HEAD"])) ?? (await git(cwd, ["diff"])) ?? "";

  const why = reason === "limited" ? "hit a usage/rate limit" : "failed";
  const parts: string[] = [
    `You are continuing a task started by another coding agent (${previousAgent}), which stopped because it ${why}.`,
    `## Original task\n${prompt}`,
  ];

  if (status === null) {
    parts.push(
      "## Working tree\nNot a git repository (or git unavailable); inspect the files directly.",
    );
  } else {
    parts.push(`## Working tree status\n${status.trim() === "" ? "(clean)" : status.trimEnd()}`);
    parts.push(`## Diff so far\n${diff.trim() === "" ? "(no changes)" : truncate(diff)}`);
  }

  if (summary) parts.push(`## Summary from previous agent\n${summary}`);
  parts.push("Continue from the current state of the working tree. Do not redo completed work.");
  return parts.join("\n\n");
}
```

```ts
import { classify } from "./detector.js";
import { buildHandoff } from "./handoff.js";
import { otherAgent, pickAgent } from "./router.js";
import type { StateStore } from "./state.js";
import type { AgentName, Attempt, Config, RunFn, TaskResult } from "./types.js";

export interface Deps {
  config: Config;
  state: StateStore;
  run: RunFn;
  now?: () => number;
}

export interface TaskRequest {
  prompt: string;
  cwd: string;
  depth: number;
  onChunk?: (text: string) => void;
}

export async function runTask(deps: Deps, req: TaskRequest): Promise<TaskResult> {
  const { config, state, run } = deps;
  const now = deps.now ?? Date.now;
  const cooling = (a: AgentName) => state.isCooling(a, now());
  const describeCooldowns = () =>
    (["claude", "codex"] as AgentName[])
      .map((a) =>
        cooling(a)
          ? `${a}: ${Math.ceil((state.cooldownUntil(a) - now()) / 60000)}m left`
          : `${a}: available`,
      )
      .join(", ");

  const record = (res: TaskResult): TaskResult => {
    state.appendJob({
      at: now(),
      agent: res.agent,
      status: res.status,
      failedOver: res.failedOver,
      promptPreview: req.prompt.slice(0, 80),
    });
    return res;
  };

  if (req.depth >= 1) {
    return {
      status: "rejected",
      agent: null,
      output: "",
      failedOver: false,
      attempts: [],
      message: "orch was called from inside an orch-spawned agent (ORCH_DEPTH >= 1); refusing to recurse",
    };
  }

  const first = pickAgent(config, req.prompt, cooling);
  if (!first) {
    return record({
      status: "unavailable",
      agent: null,
      output: "",
      failedOver: false,
      attempts: [],
      message: `Both agents are cooling down (${describeCooldowns()})`,
    });
  }

  const runAttempt = async (agent: AgentName, prompt: string) => {
    const cfg = config.agents[agent];
    const result = await run(cfg.command, cfg.args, prompt, {
      cwd: req.cwd,
      depth: req.depth,
      onChunk: req.onChunk,
    });
    const outcome = classify(result, cfg.limitPatterns);
    if (outcome === "limited") state.setCooldown(agent, now() + cfg.defaultCooldownSec * 1000);
    const attempt: Attempt = { agent, outcome, exitCode: result.exitCode, stderr: result.stderr };
    return { result, outcome, attempt };
  };

  const a1 = await runAttempt(first, req.prompt);
  if (a1.outcome === "ok") {
    return record({
      status: "ok",
      agent: first,
      output: a1.result.stdout,
      failedOver: false,
      attempts: [a1.attempt],
    });
  }

  const second = otherAgent(first);
  if (cooling(second)) {
    return record({
      status: "failed",
      agent: first,
      output: a1.result.stdout,
      failedOver: false,
      attempts: [a1.attempt],
      message: `${first} ${a1.outcome}; ${second} unavailable (${describeCooldowns()})`,
    });
  }

  const handoff = await buildHandoff({
    prompt: req.prompt,
    cwd: req.cwd,
    previousAgent: first,
    reason: a1.outcome,
  });
  const a2 = await runAttempt(second, handoff);
  return record({
    status: a2.outcome === "ok" ? "ok" : "failed",
    agent: second,
    output: a2.result.stdout,
    failedOver: true,
    attempts: [a1.attempt, a2.attempt],
    message:
      a2.outcome === "ok"
        ? undefined
        : `${first} ${a1.outcome}, then ${second} ${a2.outcome}: ${a2.result.stderr.trim().slice(0, 300)}`,
  });
}
```

- Produces:
  - `Request = { type: "run"; prompt: string; cwd: string; depth: number } | { type: "status" } | { type: "shutdown" }`
  - `Message = { type: "chunk"; text: string } | { type: "result"; result: TaskResult } | { type: "status"; cooldowns: Partial<Record<AgentName, number>>; jobs: JobEntry[] } | { type: "ok" } | { type: "error"; message: string }`

  - `sendRequest(sockPath: string, req: Request, onChunk: (m: Message) => void): Promise<Message>` — resolves with the first non-chunk message, rejects on socket error or early close.
  - `connectOrStart(sockPath: string, timeoutMs?: number): Promise<void>` — spawns a detached daemon if none is alive.
  - `startDaemon(opts: { sockPath: string; deps: Deps; onShutdown?: () => void }): Promise<{ close(): Promise<void> }>`

- [ ] **Step 2: Write `src/daemon/client.ts`**

```ts
import { spawn } from "node:child_process";
import net from "node:net";
import { fileURLToPath } from "node:url";
import type { Message, Request } from "./protocol.js";

export function isAlive(sockPath: string): Promise<boolean> {
  return new Promise((resolve) => {
    const c = net.connect(sockPath);
    c.once("connect", () => {
      c.destroy();
      resolve(true);
    });
    c.once("error", () => resolve(false));
  });
}

export function sendRequest(
  sockPath: string,
  req: Request,
  onChunk: (m: Message) => void,
): Promise<Message> {
  return new Promise((resolve, reject) => {
    const socket = net.connect(sockPath);
    let buf = "";
    let done = false;
    socket.on("connect", () => socket.write(`${JSON.stringify(req)}\n`));
    socket.on("data", (d) => {
      buf += d.toString();
      let i: number;
      while ((i = buf.indexOf("\n")) >= 0) {
        const line = buf.slice(0, i);
        buf = buf.slice(i + 1);
        if (!line.trim()) continue;
        const msg = JSON.parse(line) as Message;
        if (msg.type === "chunk") {
          onChunk(msg);
        } else {
          done = true;
          socket.destroy();
          resolve(msg);
          return;
        }
      }
    });
    socket.on("error", (e) => {
      if (!done) reject(e);
    });
    socket.on("close", () => {
      if (!done) reject(new Error("daemon closed the connection before replying"));
    });
  });
}

export async function connectOrStart(sockPath: string, timeoutMs = 5000): Promise<void> {
  if (await isAlive(sockPath)) return;
  const entry = fileURLToPath(new URL("./index.js", import.meta.url));
  spawn(process.execPath, [entry], { detached: true, stdio: "ignore" }).unref();
  const deadline = Date.now() + timeoutMs;
  while (Date.now() < deadline) {
    await new Promise((r) => setTimeout(r, 100));
    if (await isAlive(sockPath)) return;
  }
  throw new Error(`orch daemon did not start within ${timeoutMs}ms`);
}
```

```ts
import { chmodSync, existsSync, mkdirSync, unlinkSync } from "node:fs";
import net from "node:net";
import { dirname } from "node:path";
import { type Deps, runTask } from "../core/orchestrator.js";
import { isAlive } from "./client.js";
import type { Message, Request } from "./protocol.js";

export interface DaemonOptions {
  sockPath: string;
  deps: Deps;
  onShutdown?: () => void;
}

export async function startDaemon(opts: DaemonOptions): Promise<{ close(): Promise<void> }> {
  const { sockPath, deps, onShutdown } = opts;
  mkdirSync(dirname(sockPath), { recursive: true, mode: 0o700 });

  if (existsSync(sockPath)) {
    if (await isAlive(sockPath)) throw new Error(`orch daemon already running at ${sockPath}`);
    unlinkSync(sockPath); // stale socket from a crashed daemon
  }

  const handle = async (socket: net.Socket, line: string) => {
    const send = (m: Message) => {
      if (!socket.destroyed) socket.write(`${JSON.stringify(m)}\n`);
    };
    let req: Request;
    try {
      req = JSON.parse(line);
    } catch {
      send({ type: "error", message: "invalid JSON" });
      return;
    }
    if (req.type === "status") {
      const s = deps.state.snapshot();
      send({ type: "status", cooldowns: s.cooldowns, jobs: s.jobs });
    } else if (req.type === "shutdown") {
      send({ type: "ok" });
      setImmediate(() => onShutdown?.());
    } else if (req.type === "run") {
      if (typeof req.prompt !== "string" || typeof req.cwd !== "string") {
        send({ type: "error", message: "run requires string prompt and cwd" });
        return;
      }
      try {
        const result = await runTask(deps, {
          prompt: req.prompt,
          cwd: req.cwd,
          depth: Number(req.depth) || 0,
          onChunk: (text) => send({ type: "chunk", text }),
        });
        send({ type: "result", result });
      } catch (e) {
        send({ type: "error", message: e instanceof Error ? e.message : String(e) });
      }
    } else {
      send({ type: "error", message: "unknown request type" });
    }
  };

  const server = net.createServer((socket) => {
    let buf = "";
    socket.on("data", (d) => {
      buf += d.toString();
      let i: number;
      while ((i = buf.indexOf("\n")) >= 0) {
        const line = buf.slice(0, i);
        buf = buf.slice(i + 1);
        if (line.trim()) void handle(socket, line);
      }
    });
    socket.on("error", () => {});
  });

  await new Promise<void>((resolve, reject) => {
    server.once("error", reject);
    server.listen(sockPath, () => resolve());
  });
  chmodSync(sockPath, 0o600);

  return {
    close: () =>
      new Promise<void>((resolve) => {
        server.close(() => {
          try {
            unlinkSync(sockPath);
          } catch {
            /* already gone */
          }
          resolve();
        });
      }),
  };
}
```

```ts
export type Command =
  | { name: "run"; prompt: string; cwd?: string }
  | { name: "status" }
  | { name: "daemon"; action: "start" | "stop" }
  | { name: "help" };

export function parseArgs(argv: string[]): Command {
  const [cmd, ...rest] = argv;
  if (cmd === "run") {
    let cwd: string | undefined;
    const words: string[] = [];
    for (let i = 0; i < rest.length; i++) {
      if (rest[i] === "--cwd") {
        cwd = rest[++i];
        if (!cwd) throw new Error("--cwd requires a directory");
        continue;
      }
      words.push(rest[i]);
    }
    const prompt = words.join(" ").trim();
    if (!prompt) throw new Error("usage: orch run [--cwd DIR] <prompt>");
    return { name: "run", prompt, cwd };
  }
  if (cmd === "status") return { name: "status" };
  if (cmd === "daemon" && (rest[0] === "start" || rest[0] === "stop")) {
    return { name: "daemon", action: rest[0] };
  }
  if (!cmd || cmd === "help" || cmd === "--help") return { name: "help" };
  throw new Error(`unknown command: ${cmd}`);
}
```

```ts
#!/usr/bin/env node
import { join, resolve } from "node:path";
import { orchHome } from "../core/config.js";
import { connectOrStart, isAlive, sendRequest } from "../daemon/client.js";
import { parseArgs } from "./args.js";

const USAGE = `usage:
  orch run [--cwd DIR] <prompt>   run a task (fails over between claude and codex)
  orch status                     show cooldowns and recent jobs
  orch daemon start|stop`;

async function main(): Promise<number> {
  const cmd = parseArgs(process.argv.slice(2));
  const sock = join(orchHome(), "sock");

  switch (cmd.name) {
    case "help":
      console.log(USAGE);
      return 0;

    case "daemon": {
      if (cmd.action === "start") {
        await connectOrStart(sock);
        console.log("orch daemon running");
        return 0;
      }
      if (!(await isAlive(sock))) {
        console.log("orch daemon not running");
        return 0;
      }
      await sendRequest(sock, { type: "shutdown" }, () => {});
      console.log("orch daemon stopped");
      return 0;
    }

    case "status": {
      await connectOrStart(sock);
      const m = await sendRequest(sock, { type: "status" }, () => {});
      if (m.type !== "status") throw new Error("unexpected reply from daemon");
      for (const agent of ["claude", "codex"] as const) {
        const until = m.cooldowns[agent] ?? 0;
        const left = Math.ceil((until - Date.now()) / 60000);
        console.log(`${agent}: ${left > 0 ? `cooling down, ${left}m left` : "available"}`);
      }
      for (const j of m.jobs.slice(-10)) {
        const when = new Date(j.at).toISOString();
        console.log(`${when} ${j.status} ${j.agent ?? "-"}${j.failedOver ? " (failover)" : ""} ${j.promptPreview}`);
      }
      return 0;
    }

    case "run": {
      await connectOrStart(sock);
      const depth = Number(process.env.ORCH_DEPTH ?? 0) || 0;
      const final = await sendRequest(
        sock,
        { type: "run", prompt: cmd.prompt, cwd: resolve(cmd.cwd ?? process.cwd()), depth },
        (m) => {
          if (m.type === "chunk") process.stdout.write(m.text);
        },
      );
      if (final.type === "error") throw new Error(final.message);
      if (final.type !== "result") throw new Error("unexpected reply from daemon");
      const r = final.result;
      if (r.failedOver) console.error(`\norch: switched agent, finished with ${r.agent}`);
      if (r.status !== "ok") {
        console.error(`orch: ${r.status}${r.message ? `: ${r.message}` : ""}`);
        return 1;
      }
      return 0;
    }
  }
}

main().then(
  (code) => process.exit(code),
  (err: Error) => {
    console.error(`orch: ${err.message}`);
    process.exit(1);
  },
);
```

```ts
  "Run a coding task via orch. Routes to Claude Code or Codex and fails over to the other on rate limit or failure.",
  { prompt: z.string(), cwd: z.string().optional() },
  async ({ prompt, cwd }) => {
    await connectOrStart(sock);
    const depth = Number(process.env.ORCH_DEPTH ?? 0) || 0;
    const final = await sendRequest(
      sock,
      { type: "run", prompt, cwd: cwd ?? process.cwd(), depth },
      () => {},
    );
    if (final.type === "error") {
      return { content: [{ type: "text" as const, text: final.message }], isError: true };

    if (final.type !== "result") {
      return { content: [{ type: "text" as const, text: "unexpected reply from daemon" }], isError: true };

    const r = final.result;
    const footer = `\n\n[orch] status=${r.status} agent=${r.agent ?? "-"} failedOver=${r.failedOver}${
      r.message ? ` message=${r.message}` : ""
    }`;
    return {
      content: [{ type: "text" as const, text: r.output + footer }],
      isError: r.status !== "ok",
    };
  },
);

server.tool("orch_status", "Show agent cooldowns and recent jobs.", {}, async () => {
  await connectOrStart(sock);
  const m = await sendRequest(sock, { type: "status" }, () => {});
  return { content: [{ type: "text" as const, text: JSON.stringify(m, null, 2) }] };
});

await server.connect(new StdioServerTransport());
```

````markdown
# orch

Local daemon that routes coding tasks to Claude Code or Codex and fails over to the other on rate limit or failure.

## Install

```bash
npm install
npm run build
npm link            # puts `orch` on your PATH
mkdir -p ~/.orch && cp config.example.yaml ~/.orch/config.yaml
```

## Use

```bash
orch run "add a health check endpoint"
orch status
orch daemon stop    # needed after editing ~/.orch/config.yaml
```

The daemon starts on demand. Cooldowns and recent jobs live in `~/.orch/state.json`.

## Register as an MCP server

```bash
claude mcp add orch -- node "$(pwd)/dist/mcp/index.js"
codex mcp add orch -- node "$(pwd)/dist/mcp/index.js"
```

If your Codex version has no `codex mcp add`, add this to `~/.codex/config.toml`:

```toml
[mcp_servers.orch]
command = "node"
args = ["/absolute/path/to/orch/dist/mcp/index.js"]
```
````
